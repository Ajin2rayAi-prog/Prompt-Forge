# Prompt-Forge — نسخه ۱ (v1)

## ✅ قابلیت‌های این نسخه
- ۹ بخش آناتومی پرامپت (موضوع → نورپردازی) با چیپ + ورودی آزاد
- ۹۹ دستور شات/ویدیو در ۹ گروه
- پیش‌نمایش انیمیشنی CSS برای هر دستور
- وزن‌دهی `(word:1.x)` با دکمه‌های تقویت/تضعیف
- پرامپت منفی با پیش‌فرض‌های آماده
- ۳ حالت خروجی: تصویر / ویدیو / سریع
- پارامترها: Steps, CFG, Sampler, Aspect Ratio, Seed
- کپی یک‌کلیکی + ذخیره + تاریخچه (localStorage)
- دوزبانه FA/EN با RTL/LTR
- دکمه‌ی «سورپرایزم کن»
