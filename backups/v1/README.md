# 🔨 Prompt-Forge

**آهنگریِ پرامپت حرفه‌ای برای هوش مصنوعی** — یک ابزار وبِ بدون نصب که با انتخاب چیپ، پرامپتِ آماده می‌سازه.

> بدون فریم‌ورک، بدون build، بدون نیاز به اینترنت — فقط `index.html` رو دابل‌کلیک کن.

## ✨ امکانات

| قابلیت | توضیح |
|--------|-------|
| 🧩 **آناتومی ۹ قسمتی** | موضوع → رسانه → سبک → هنرمند → سایت → کیفیت → جزئیات → رنگ → نور (به ترتیب وزن) |
| 🎬 **۹۹ دستور شات** | ۹ گروه: دوربین، زاویه، اکشن، نورپردازی، ترکیب‌بندی، افکت، فوکوس، رنگ، پرتره |
| ▶️ **پیش‌نمایش زنده** | هر دستور یه مینی‌پلییر CSS داره که همون افکت رو نشون می‌ده |
| ⚖️ **وزن‌دهی** | `(word:1.2)` با دکمه‌های تقویت/تضعیف |
| 🚫 **پرامپت منفی** | پیش‌فرض‌های آماده + امکان سفارشی |
| 🖼🎬⚡ **۳ حالت خروجی** | تصویر (SD/Midjourney) · ویدیو (Runway/Pika/Kling) · سریع (ترکیبی) |
| 🎲 **سورپرایزم کن** | یه پرامپتِ کاملِ تصادفی می‌سازه |
| 💾 **تاریخچه** | ذخیره در localStorage + کپی/حذف |
| 🌐 **دوزبانه** | فارسی (RTL) و انگلیسی (LTR) |
| ⚙️ **پارامترها** | Steps · CFG · Sampler · Aspect Ratio · Seed |

## 🚀 استفاده

1. فایل `index.html` رو با مرورگر باز کن
2. از تب **آناتومی** یا **دستورات شات** چیپ‌ها رو انتخاب کن
3. پرامپت تو پنلِ سمت (راست/چپ) زنده ساخته میشه
4. **کپی** کن و به هر هوش مصنوعی که خواستی بده

## 📁 ساختار

```
Prompt-Forge/
├── index.html   ← صفحه
├── style.css    ← استایل + انیمیشن‌ها
├── data.js      ← داده‌ها (۹۹ دستور + آناتومی + ترجمه)
├── app.js       ← منطق
└── backups/     ← بکاپ شماره‌دار
```
