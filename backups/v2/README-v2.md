# Prompt-Forge — نسخه ۲ (v2)

## ✅ قابلیت‌های این نسخه (نسبت به v1)
- 🧭 **رابط ویزاردی مرحله‌به‌مرحله** — دیگه اسکرول نیست؛ هر صفحه یه سوال
- 📖 **خلاصه‌ی فارسی پرامپت** — صفحه‌ی آخر به فارسی میگه کل پرامپت چی میگه
- 💎 **طراحی پریمیوم** — glassmorphism، نوار پیشرفت، انیمیشن نرم بین مراحل
- 🎯 **انتخاب حالت** (تصویر / ویدیو / ترکیبی) در اولین قدم
- 🌐 **دوزبانه FA/EN** با RTL/LTR
- 🎬 **۹۹ دستور شات** با پیش‌نمایش انیمیشنی + تب گروه‌ها
- ⚙️ **پارامترهای فنی** (Steps/CFG/Sampler/AR/Seed)
- 💾 **تاریخچه** در localStorage + کشوی جانبی
- 🎲 **سورپرایزم کن** (مستقیم میپره صفحه‌ی آخر)
