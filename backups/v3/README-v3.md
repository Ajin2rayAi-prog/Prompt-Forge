# Prompt-Forge — نسخه ۳ (v3)

## ✅ قابلیت‌های جدید
- 🎨 **شمای بصری برای هر چیپ** — هر گزینه (سبک، رسانه، هنرمند، رنگ...) یه پشت‌تصویر CSS داره که حسش رو نشون میده (۷۲ شمای یکتا)
- 💬 **توضیح «این یعنی چی؟»** — هر چیپ یه توضیح خودمانی فارسی داره (مثلاً سوررئال: «مثل خواب: چیزهای غیرممکن کنار هم»)
- 🗂 **۶ قالب آماده (Preset)** — حماسی فانتزی، سایبرپانک، جیبلی، پرتره، سوررئال، نوآر — با یک کلیک همه‌چیز پر میشه
- ⚖️ **اسلایدر وزن** — تو مرحله‌ی ترجمه، وزن هر کلمه رو از ۰.۴× تا ۲.۴× بکش
- 🔢 **شمارش توکن زنده** — کنار پرامپت و پرامپت منفی
- ⬆️⬇️ **اکسپورت/ایمپورت تاریخچه** — فایل JSON
