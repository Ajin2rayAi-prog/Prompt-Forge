# Prompt-Forge — نسخه ۲.۲ (v2.2)

## ✅ قابلیت‌های این نسخه (نسبت به v2)
- 🌐 **ترجمه‌ی خودکار فارسی → انگلیسی** — کاربر می‌تونه فارسی تایپ کنه، پرامپت نهایی انگلیسی میشه
- 📖 **مرحله‌ی «بررسی ترجمه»** — قبل از خروجی نهایی، کاربر می‌بینه هرچی نوشته به چی تبدیل شده
- 📚 **دیکشنری آفلاین** (~۱۸۰ کلمه) — بدون اینترنت هم کلماتمعروف ترجمه میشن
- ☁️ **API آنلاین** (MyMemory) — برای جملات کامل، ترجمه‌ی طبیعی‌تر میده
- ✎ **چیپ‌های دلخواه قابل‌حذف** — متن دلخواه مثل چیپ‌ها میشه و با کلیک حذف میشه

## 🧪 تست‌ها
- ۲۰ تست ویزارد (مسیر کامل + سورپرایز + زبان)
- ۱۰ تست ترجمه (دیکشنری + API + پرامپت نهایی)
- API واقعی تأیید شد: «یک شیر قدرتمند در جنگل تاریک» → "A powerful lion in the dark forest"
